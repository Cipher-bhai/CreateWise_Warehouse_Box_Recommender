Why CrateWise

Built for warehouses that hate wasted packaging spend

Deterministic recommendation engine

Every product is matched against every box using a clear must-fit rule, cheapest-wins logic, and a wasted-volume tiebreaker — fully unit tested.

AI-generated explanations

Every recommendation ships with a one-sentence, human-readable explanation — powered by a free-tier LLM with an automatic offline fallback.

Role-based access

Admins, Managers, and Staff each see exactly what they need — from full user management down to simple order creation.

Live dashboard & charts

Order status, box usage, and catalog size at a glance — rendered with Chart.js from real-time queryset aggregation.

REST API included

A full Django REST Framework API for Products, Boxes, and Orders — ready to plug into a mobile app or another service.

Tested & documented

36+ automated tests covering models, the algorithm, auth, and CRUD permissions, with real coverage reports checked in.
